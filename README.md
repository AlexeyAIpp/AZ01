# AZ01 — анализ данных с pandas

Проект на Python для работы с CSV-файлами
и анализа данных с помощью библиотеки pandas.

## Содержимое проекта

- task1.py — первое задание.
- task2.py — задание на  расчёт средней зарплаты по городам.
- World-happiness-report-updated_2024.csv — исходные данные в первом задании для анализа.
- dz.csv — исходные данные во втором задании для анализа.

## Запуск

1. Установить Python и библиотеку pandas: `pip install pandas`.
2. Открыть папку проекта.
3. Выполнить: `python tas1.py`
4.       или: `python task2.py`.
